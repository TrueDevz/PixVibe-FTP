# 🚀 LocalFTP - Direct High-Speed File Transmitter (~30GB+ Ready)

**LocalFTP** is a high-speed, direct PC-to-PC transmitter built to share large files and collections (videos, raw footage, datasets, images, documents) across the Internet or on your local network — **without uploading to Google Drive or any cloud storage**.

---

## 🌟 Key Features:
1. **Multi-File & Folder Bundling**:
   - Select multiple files or entire folders at once.
   - Recipients get a beautiful collection gallery where they can browse and download only the specific files they need (or download all as a ZIP).
2. **Interactive In-Browser Media Previews**:
   - 🎥 **Videos** (MP4, MKV, WebM, MOV): Stream and seek directly inside the browser using HTML5 video with Range requests.
   - 🖼️ **Images** (JPG, PNG, WebP, GIF, SVG): Instant full-screen lightbox preview.
   - 📄 **PDFs & Documents**: Embedded PDF reader and code/text viewer.
   - 🎵 **Audio**: Built-in audio player.
3. **Optional Link Password Protection**:
   - Set an optional passkey when creating a share.
   - Protects sensitive and important files so only authorized users can view or download.
4. **Permanent Static URL via Ngrok & Cloudflare**:
   - Pre-configured with static domain `unmobbed-corrina-mustily.ngrok-free.dev`.
   - Never changes even if internet disconnects, router reboots, or PC restarts!
5. **RFC 7233 Resume Support**:
   - Pause and resume anytime in browsers, **IDM (Internet Download Manager)**, and FDM.

---

## 🛠️ How to Run:

Simply double-click:
```
run.bat
```
Or run in terminal:
```bash
python main.py
```

It will automatically:
1. Launch the local web server.
2. Connect your static Ngrok tunnel (`unmobbed-corrina-mustily.ngrok-free.dev`).
3. Open the **LocalFTP Control Dashboard** in your web browser (`http://127.0.0.1:8000`).
